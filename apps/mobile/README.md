# App do agricultor (Expo)

App offline-first do agricultor. As telas e textos estão no [guia do front-end, Parte A](../../documentacao/3-guia-front-end.md#parte-a-experiência-do-agricultor-ux), e a construção, na Parte C.

- `pnpm --filter @agrofacil/mobile start`: abre o Metro.
- Use um **development build** (`npx expo run:android`), não o Expo Go (doc 3 §C.1).
