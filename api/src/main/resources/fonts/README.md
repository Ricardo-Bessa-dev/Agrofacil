# Fontes dos PDFs

Noto Sans (Regular e Bold), embutida nos relatórios e documentos gerados para que os acentos saiam
iguais em qualquer computador (doc 2 §1.14).

- Origem: projeto Noto, do Google (https://notofonts.github.io), copiada do pacote `fonts-noto-core`.
- Licença: SIL Open Font License 1.1 (https://openfontlicense.org). A licença permite embutir e
  redistribuir a fonte junto com o software.
